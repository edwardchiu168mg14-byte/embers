## CodexIsland

Embers' macOS build script follows the approach used by CodexIsland
(<https://github.com/ericjypark/codex-island>): compiling with `swiftc` directly, writing
`Info.plist` by hand, combining architectures with `lipo`, and ad-hoc signing with `codesign`.
No CodexIsland source code is included at this time. If code is reused later, its license
text will be reproduced here.
